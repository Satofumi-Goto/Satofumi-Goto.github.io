# 遠隔監視・操作コンソール（remote-ops）

レベル4自動運転MaaS（ロボタクシー8台・シャトル4台）を遠隔監視者が監視・支援するためのコンソールです。
**表示値はすべて合成データによる訓練用シミュレーション**であり、実車・実運行には接続していません。

公開URL: `/remote-ops/`（ビルド不要の静的ページ。ES Modules）

## 画面構成

| 領域 | 内容 |
|---|---|
| ヘッダー | 走行・停留所・支援要求・MRM/MRC・通信劣化・充電/運休・P1未受付の件数、JST時計とシフト、消音（60秒で自動解除）、引継ぎ、レポート、訓練シナリオ |
| KPI | 監視比率、遠隔支援/100km、平均受付時間、受付SLA遵守率、平均解決時間、配車待ち予約（平均待ち・保留・キャンセル）、迎車遅延、完了乗車 |
| 左 | アラート・支援要求キュー（優先度→未受付→発生順、SLAバー、担当者、エスカレーション）、車両一覧 |
| 中央 | 運行地図（ODDゾーン、停留所、ハブ、封鎖区間、信号滅灯、経路、現場要員）、イベントログ／予約・利用者影響／ゾーン・ODD／チーム |
| 右 | 選択車両：事案とSOPチェックリスト、車載カメラ6面（前・後・左・右・車内・BEV）、車両状態・通信、遠隔指令、指令履歴 |

## 運用ルール（実装されている安全設計）

- **遠隔支援であって遠隔運転ではない。** 回避経路承認・進行承認は「判断の提供」で、車両の検知・停止機能は常に有効。
- **インターロック。** RTT 300 ms以上、通信途絶、ドア開、診断未合格／不合格、SOP目視確認未完了、ゾーン停止中、接触事案中などでは危険度の高い指令を受け付けない。無効なボタンには理由を常時表示。
- **見ずにチェックさせない。** カメラ指定のある確認手順は、該当カメラをメイン表示で1.5秒以上見るまでチェックできない。
- **受付SLA。** P1 10秒／P2 30秒／P3 120秒。超過は監督者へ自動エスカレーション。P1未受付は警報を繰り返す。
- **通信途絶時は車両が自律的に安全停止。** 3秒の途絶で車両側ウォッチドッグがMRMを実行。指令は「送信→車両応答→実行」を追跡し、5秒で未達を明示。
- **確認ダイアログ。** 影響の大きい指令は実行内容・前提条件・SOP進捗を示して確認。緊急停止は1秒長押し（E長押し）。
- **記録。** すべての操作は時刻・操作者付きでログと事案記録票に残り、テキスト／JSON／CSVで出力できる。

## 事象とSOP（14種）

路上障害物、歩行者滞留、信号滅灯、緊急車両接近、LiDAR性能低下、通信品質劣化、通信途絶→MRM、システム異常MRM、車内非常通報、接触の疑い、豪雨によるODD逸脱リスク、ドア閉扉異常、SOC低下、車椅子乗車支援。
定義は `sim.js` の `ITYPES`（手順・必須条件・推奨指令）にあります。

## キーボード

`J/K` アラート移動 · `Enter` 先頭を開く · `A` 受付 · `R` 対応完了 · `1–6` カメラ · `[ ]` 前後の車両 · `F` 追従 · `G` 全体表示 · `P` 車内放送 · `T` 車内通話 · `H` ハザード · `E`長押し 緊急停止 · `M` 消音 · `?` ガイド · `Esc` 閉じる

## 訓練シナリオ

事象の個別発生、多重障害、シミュレーション速度（⏸/1×/2×/4×）、発生頻度、チーム自動分担、**自動デモ**（全事案を同僚がSOPどおり処理）を切り替えられます。

## ファイル

| ファイル | 役割 |
|---|---|
| `world.js` | 合成市街地の道路網・ODDゾーン・停留所・経路探索 |
| `sim.js` | 車両・予約（MaaS）・事案・SOP・指令・インターロック・チームのシミュレーション |
| `render.js` | 運行地図と車載カメラ／BEVの描画 |
| `app.js` | 画面・操作・ダイアログ・音・ショートカット |
| `i18n.js` | 日本語／英語 |
| `tests/sim.test.mjs` | 回帰テスト（`node remote-ops/tests/sim.test.mjs`） |

テストは、全事象のSOP完遂、主要インターロック、自動デモでの2時間連続運転（事案の滞留・強制クローズなし）、翻訳キーの網羅を確認します。
